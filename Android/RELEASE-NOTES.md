Android 0.4.3 makes router connections manual at startup. Open the app and choose a saved router, scan the local network, or use Bluetooth tools without waiting for an automatic search. Changing sections reuses the current authenticated connection. Page loads show query progress and stop after a connection failure; Refresh reconnects when needed.

New status summaries in Overview, Bluetooth inspection and WOBA inspection distinguish primary/satellite role, bridge/router mode, onboarding completion, WAN link and firmware activity. Readings show their source and time. Missing values remain Unknown, and earlier WOBA readings are labelled as prior observations. Onboarding completion comes from an explicit router response; LED colours and Bluetooth UPGRADING are not treated as proof. A WAN link being Up does not establish Internet access.

The WOBA inspection screen adds an experimental Finish onboarding action. It verifies a saved normal admin login, automatically matches the selected Bluetooth unit, refreshes identity/update checks, and sends SETOBCOMPLETE once after review. A separate check verifies normal admin access and the router's completion flag. An uncertain write is never automatically retried. This path is limited to the previously inspected W30 firmware AXR.0814.240522.10 and still requires physical-router validation; it cannot proceed if required Bluetooth identity reads are unavailable.

Band steering and DFS channels appear prominently in Wi-Fi settings. If the router omits or rejects their settings, the app displays the read result instead of hiding the options. The existing reviewed editors remain available for recognized on/off values.

Bluetooth model, serial and WAN-MAC read failures now have clearer diagnostics, including GATT 115 (0x73), a diagnostic-log shortcut and explicit reconnect. Other readable state fields remain available. The cause of code 115 on the owner's router and the reported connectivity loss after changing LED brightness remain unresolved; this release does not claim to repair those hardware observations.

Release checks cover shared protocol/status logic, identity and update guards, no repeated section discovery, interrupted page loads, Bluetooth callback errors, Android Keystore, real HTTPS fixture login/cookies, update signing and credential retention. Complete offline factory setup and satellite pairing retain their physical-validation limitations.
