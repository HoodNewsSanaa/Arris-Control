Android 0.4.0 makes Bluetooth setup and local Wi-Fi management the primary connection flow. Existing local logins, network discovery and encrypted pending-setup recovery are accessible without opening ARRIS account options. Optional account acquisition is collapsed; automatic GitHub update checks are off by default for new installations.

The new triangle mesh view shows known routers and only reported backhaul connections, with directional PHY rates and signal when a unique MAC correlation is available. Unknown parents, missing rates and unmeasured throughput are explicit. It displays a dated snapshot with manual refresh, not live throughput. Node selection is available by touch and accessible buttons.

Add a mesh node opens Bluetooth inspection, reviewed local controller discovery controls and topology refresh. This does not establish complete offline pairing: Bluetooth factory setup and end-to-end satellite pairing still need spare-unit hardware validation. No ARRIS account is used by the local actions; firmware cloud independence remains unproven. No root installation or firmware flashing was added.

Offline tests cover client exclusion, identity/MAC correlation, missing and ambiguous links, standard kbit/s conversion, discovery read/write aliases and bounds, and write-only acknowledgement handling. Existing Bluetooth, credentials, pinning and no-retry tests remain. CI exercises the installed Android APK, encrypted credential retention and triangle rendering using fictional data.
