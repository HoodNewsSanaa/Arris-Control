# SURFboard mAX Bluetooth onboarding (research notes)

Status: **research only, not implemented, not tested on hardware.**
Source: static analysis of the user's own copy of SURFboard Central 4.3.5
(`com.arris.sbc`, version code 232). Nothing from the APK is redistributed here;
this document describes behaviour in our own words so Arris Control can decide
whether factory setup without the vendor app is feasible.

## Summary

- First-time setup of a mAX router does **not** use the local HTTPS API on
  port 50011. It runs over **Bluetooth LE GATT**.
- The router's local management password is **generated by the phone app**
  (random), encrypted with a key the router supplies over Bluetooth, and
  written to the router. The same password is what Arris Control later
  recovers from the ARRIS account (`SSOEncryptedPassword`).
- The vendor flow also makes a **cloud device registration** call in the
  middle of the sequence. Whether the router needs that call to finish setup
  is the main open question (see below).

## GATT services

Both services use the Bluetooth base UUID (`0000xxxx-0000-1000-8000-00805f9b34fb`).

| Short ID | Name in app | Purpose (as used by the app) |
|---|---|---|
| `aa00` | `SERVICE_OBA` | Onboarding agent: identity, state, firmware |
| `ab00` | `SERVICE_LCA` | Local credentials and Wi-Fi configuration |

### Characteristics used during setup

| Short ID | Name in app | Direction | Notes |
|---|---|---|---|
| `aa04` | `SerialNo` | read | Router serial |
| `aa05` | `WanMac` | read | WAN MAC (matches the TLS certificate CN / `ExpectedMac`) |
| `aa06` | `ModelNumber` | read | e.g. W133 |
| `aa07` | `DeviceMode` | read | Operating mode |
| `aa08` | `OBAState` | read | Onboarding state |
| `aa11` | `WanStatus` | read | WAN link status |
| `aa14` | `FriendlyName` | write | Display name |
| `aa16` / `aa0F` | `SetTimeZone` / `SetTime` | write | Clock setup |
| `aa18` | `RouterPassword` | write | Present in the attribute list; role not yet traced |
| `aa1a` | `OBA_COMPLETE` | write | Marks onboarding finished |
| `ab0a` | `Encryption_Key` | read | Key used to encrypt values written to the router |
| `ab01`–`ab04` | `P11`–`P14 WifiSSID` | write | Fronthaul SSID per radio/profile |
| `ab05`–`ab08` | `P11`–`P14 WifiPASSPHRASE` | write | Fronthaul passphrase |
| `ab13`–`ab16` | `P11`–`P14 BHWifiSSID` | write | Backhaul SSID |
| `ab17`–`ab1a` | `P11`–`P14 BHWifiPASSPHRASE` | write | Backhaul passphrase |
| `ab1c` | `SET_TYPE` | write | Selects what the `ab1d`–`ab20` slots carry (`SET:<n>`) |
| `ab1d`–`ab20` | `P11`–`P14 USER_NAME_PWD` | read/write | Four slots, used in sequence |

Firmware characteristics (`aa09`–`aa13`, `aa0C`) exist for version reporting
and upgrades; they are out of scope.

## Sequence observed in the app

This is the approximate order the registration screens drive, reconstructed
from callbacks; the exact interleaving of steps 4–7 should be confirmed.
Steps marked *(cloud)* contact ARRIS servers.

1. Scan for the router's BLE advertisement and connect.
2. Read serial (`aa04`), WAN MAC (`aa05`), model (`aa06`) and the encryption
   key (`ab0a`).
3. **Physical hash:** write `SET:3` to `SET_TYPE`, then read the four
   `USER_NAME_PWD` slots in order (`ab1d` → `ab20`) and concatenate them. The
   app treats this as a device-specific value read from the unit itself; how
   it is used afterwards has not been traced yet.
4. *(cloud)* **Device registration:** `POST /account/account-service/cpedevice`
   on the ECO account service (the same `api1.surfboardconnect.com` base
   Arris Control already reads for acquisition), with the serial, MAC and
   model. Retries on failure; failures surface as setup errors.
5. **Local credential:** the app generates a random password (or reuses one it
   already cached), writes `SET:1` to `SET_TYPE`, then writes the username and
   password through the `USER_NAME_PWD` slots.
6. Write Wi-Fi SSIDs and passphrases (fronthaul and backhaul), name and time.
7. *(cloud)* Upload the password encrypted with the account's SSO key
   (AES-CBC, same fixed IV Arris Control already uses in
   `CloudAcquisition.Decrypt`), so the account can later return it.
8. Write `OBA_COMPLETE` (`aa1a`).
9. Join the new Wi-Fi and log in locally (`/loginAction`) with the account
   email and the generated password.

## Encryption of written values

Values written to the router are encrypted with AES-CBC / PKCS#5 padding,
using the key read from `ab0a` and the same fixed 16-byte IV seen elsewhere
in the app. The exact byte layout of the username/password split across the
four slots (and any encoding before encryption) still needs to be confirmed
from the model classes before anything is implemented.

## Open questions (must be answered before implementing)

1. **Does the router require step 4 (cloud registration)?** If the router
   only needs the Bluetooth writes, setup without an ARRIS account is
   possible. If activation is gated on the cloud, Arris Control could replace
   the app but not the cloud.
2. **What is the physical hash for?** It may be sent to the cloud as proof of
   physical possession, or checked locally. This decides whether step 3 can be
   skipped.
3. **Exact payload format** for `SET_TYPE` values other than 1 and 3, and for
   the four credential slots.
4. **Role of `RouterPassword` (`aa18`)** versus the `USER_NAME_PWD` slots.
5. **Satellite/extender units:** the app has separate paths
   (`P11`…`P14` map to router and extenders); a W133 pair may need both.

## Risks

- A wrong or partial sequence on a factory-reset router could leave it in a
  state that only the vendor app can recover.
- Every check needs physical hardware and a factory reset, which erases the
  router's settings.
- Android Bluetooth permissions (`BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT`, and
  location on older Android) would be new for Arris Control.

## Suggested next step

Trace the payload format (open question 3) and the physical-hash use
(question 2) statically, then test with a **spare** unit: capture what a
factory-reset router exposes over Bluetooth with a generic BLE explorer
(read-only) before writing anything.
